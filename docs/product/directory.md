# 目录鱼骨

```text
        apps ── gateway · web · cli
          │
packages ─┼─ core · channel · plugin-sdk · workflow · mcp-host · llm · shared
          │
workers ──┼─ go-pump · python-tools
          │
     脊骨 ═ Fengyun-Nexus
          │
plugins ──┼─ templates（本地脚手架）· 远程仓挂载示例/基础/标准
          │
 skills ──┼─ nexus-dev · nexus-plugin · nexus-uia
          │
   docs ──┴─ product · ecosystem
```

```text
Fengyun-Nexus/
├── apps/                 # gateway · web · cli
├── packages/             # 核心能力包
├── workers/              # 辅助运行时
├── plugins/templates/    # 插件模板
├── skills/               # Agent 技能
├── docs/product/         # 对外产品文档
├── docs/ecosystem/       # 插件生态说明
├── configs/              # 三环境 · 管理 · 远程源
├── LICENSE
└── README.md
```
