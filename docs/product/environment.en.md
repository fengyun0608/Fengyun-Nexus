# Environment & Installation

[← 中文](environment.md)

**Required:** Node.js ≥ 20, pnpm, Git, browser.  
**Platforms:** Windows / Linux / macOS / Termux.

## Deploy

```bash
git clone https://gitcode.com/fengyunnb_admin/Fengyun-Nexus.git
cd Fengyun-Nexus
# Windows: start.bat
chmod +x boot.sh && ./boot.sh   # Linux/macOS/Termux
```

Open **only** http://127.0.0.1:8787/

Local secrets (`.env`, `configs/*.local.json`) are never uploaded.
