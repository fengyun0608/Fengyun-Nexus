# Fengyun Nexus 产品介绍

中文 | [English](README.en.md)（若暂无英页，见仓库根 README）

**Fengyun Nexus** 是可扩展的 AI 对话与自动化枢纽：一套控制台，覆盖对话、通道、插件、工作流与日常管理。

## 定位

- 面向个人与小团队的本地 / 自托管枢纽
- 品牌名始终为 **Fengyun Nexus**（不做中文商品名替代）
- 界面默认中文，可切换 English

## 适合谁

- 想把 QQ 等消息通道与机器人能力接到同一套控制台的人
- 需要插件分层（通道插件 / 框架插件）与简单管理指令的人
- 希望电脑、服务器、手机都能用的人

## 你将获得

| 能力 | 说明 |
|------|------|
| 统一控制台 | 对话、通道、插件、看板、配置同页完成 |
| 消息通道 | 可插拔；内置 QQ（OneBot 11）等 |
| 插件 | 通道插件与框架插件分类管理 |
| AI | 多供应商，可切换；未配置时不强行乱回 |
| 数据看板 | 状态汇总，可查看原始数据 |
| 管理指令 | 统一以 `#` 开头 |
